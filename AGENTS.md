# AGENTS.md — AI Foundry Desk

AI Foundry Desk turns a personal computer into a manageable multi-agent development environment. It gives your agents a consistent foundation, a shared set of practical tools, and controlled ways to install, inspect, repair, and synchronize the environment.

## Working model

This project is maintained by a small team and welcomes focused bug fixes, documentation, tests, platform evidence, and small capability improvements. Read [CONTRIBUTING.md](CONTRIBUTING.md) for the contribution flow, development setup, and testing requirements.

## How work enters this repo

- **Proposals and roadmap**: planned work and capability additions are tracked in [docs/ROADMAP.md](docs/ROADMAP.md) under the `Ready` and `Next cycle` sections.
- **Session handoff**: cross-session and cross-agent continuity is documented in [docs/NEXT-SESSION.md](docs/NEXT-SESSION.md).
- **Bug reports**: submitted via the [GitHub bug report template](.github/ISSUE_TEMPLATE/bug_report.yml); include reproduction steps and environment details.
- **Feature requests**: submitted via the [GitHub feature request template](.github/ISSUE_TEMPLATE/feature_request.yml); include the problem being solved and proposed approach.
- **Architecture changes**: open a proposal issue for broad or security-sensitive changes; wait for scope agreement before implementation.
- **Branch naming**: use `fix/<description>`, `feat/<description>`, or `docs/<description>` from `main`.
- **Pull requests**: complete the [pull request template](.github/PULL_REQUEST_TEMPLATE.md); link any relevant issues and include validation evidence. PRs are reviewed before merge.
